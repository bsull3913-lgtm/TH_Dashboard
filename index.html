Garmin 수면 CSV 가져오기
📂 클릭하거나 CSV를 여기에 드래그
Garmin Connect → 수면 → 내보내기(CSV)
CSV 컬럼 안내
자동으로 인식하는 컬럼:
• 날짜 / Date
• 수면 점수 / Sleep Score
• 수면 시간 / Total Sleep
• 취침 / Bedtime   기상 / Wake
• 심박수 / Heart Rate   HRV
• 바디 배터리 / Body Battery
수면 달력
🟢 우수(≥85)🟣 좋음(≥75)🟡 보통(≥65)🔴 낮음(<65)
수면 점수 트렌드 (최근 30일)
수면 시간 vs 필요 수면 (최근 30일)
수면 기록 (최근 30일)
